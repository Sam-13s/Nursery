# 🌿 LittleLeap Nursery

## ✨ Features

- **Responsive Design**: Fully responsive layout that works on desktop, tablet, and mobile devices
- **Interactive Plant Gallery**: Showcase of various plant collections with hover effects and animations
- **Smooth Scrolling Navigation**: Seamless navigation between sections with smooth scroll behavior
- **Contact Form**: Functional contact form with validation and user feedback
- **Newsletter Signup**: Email subscription form in the footer
- **Animations**: CSS animations and JavaScript-powered effects for enhanced user experience
- **Social Media Links**: Placeholder social media integration
- **Accessibility**: Proper semantic HTML and ARIA labels for better accessibility

## 🛠 Technologies Used

- **HTML5**: Semantic markup for structure
- **CSS3**: Custom styling with responsive design and animations
- **JavaScript (ES6+)**: Interactive functionality and DOM manipulation
- **Bootstrap 5.3.0**: CSS framework for responsive grid and components
- **Font Awesome 6.0.0**: Icon library for social media and decorative elements

## 🚀 Setup and Installation

1. **Clone or Download**: Download all files to your local machine
2. **Open in Browser**: Simply open `nursery.html` in any modern web browser
3. **No Server Required**: This is a static website that runs entirely in the browser

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection for loading Bootstrap and Font Awesome from CDNs

## 📖 Usage

### Navigation
- Use the navigation bar to jump to different sections of the site
- Smooth scrolling is enabled for a better user experience

### Plant Gallery
- Browse through different plant categories
- Click "Learn More" buttons to visit external resources about each plant type
- Hover over plant cards for interactive effects

### Contact Form
- Fill out the contact form with your name, email, and message
- Form validation ensures all fields are filled and email is valid
- Submit to receive a confirmation message

### Newsletter Signup
- Enter your email in the footer newsletter form
- Receive updates about plant tips and offers (placeholder functionality)
